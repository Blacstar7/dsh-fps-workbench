# Four-pointed star（FPS）

FPS 是 DeepSeek Harness（DSH）的会话工作台：看清长任务进度，留住未发送的草稿，找到最终产物。工具摘要、任务状态、原生产物预览、本机附件恢复、服务商用量和可选图片工具集中在同一处。浅色与深色外观跟随 DSH；会话、执行权限、语音转写和预览继续使用原生系统。

## 主要功能

- **上下文与会话产物**。点会话顶栏的「上下文」按钮，查看模型、会话状态和上下文占用估算。「输出内容」汇集会话生成或明确链接的本地文件，点击后用 DSH 原生预览打开。顶栏也可切换文件、终端和浏览器。
- **工具步骤摘要**。连续的读文件、执行命令和编辑操作会汇总成一行，展开可查看 DSH 原生详情。任务列表区分已完成、进行中和待处理。会话运行时，`ThinKing` 显示用时和 FPS 标志动画，遵循系统的减少动态效果设置。
- **输入与附件草稿**。支持粘贴图片，也可从「添加」菜单选择图片和文件。切换会话再回来时，会恢复该会话的文字草稿和未发送的附件。未发送附件保存在本机，同一客户端配置下重新加载后也能恢复。DSH 接收消息后、手动移除附件后，或附件连续 30 天未修改后的下次加载时会清除。关闭前请等待保存完成提示；存储失败时保留当前内存草稿并提供重试。加载草稿时仍可编辑文字、使用语音；发送需等待加载完成或报错。每次存储操作设有 10 秒超时。此功能不跨设备同步。每条消息最多可添加 4 张各 8 MB 的图片和 6 个各 20 MB 的文件。
- **长任务状态**。上下文侧栏分别显示 DSH 当前报告的原生计划与后台任务；后续回合可能替换或清空计划。进行中的任务显示真实状态、用时和 DSH 返回的进度信息；已结束任务折叠显示。通过原生任务按钮查看日志或停止任务。开始渲染不会自动创建计划列表，FPS 也不会估算没有依据的完成百分比。
- **兼容性自检**。打开「插件 → Four-pointed star → 兼容性自检」，检查输入、文件、预览、后台任务及本机草稿存储接口。可重新检查或复制不包含 Key、文件路径和对话内容的诊断摘要。自检只检查接口能力，不调用模型或执行工具。输入框接口不匹配或 FPS 输入框渲染报错时，本次页面自动回退到 DSH 原生输入框。
- **纯文本模型识图**。如果所选模型不支持图片输入，FPS 会从 DSH 的可用模型中查找支持图片的模型，将图片和问题发给它，再把生成的描述交给当前会话。没有写死回退模型；额外模型请求可能产生服务商费用。找不到可用模型时，输入框会保留草稿并提示失败。
- **会话和工作区**。左栏保留 DSH 的原生工作区、会话搜索和设置。侧栏按钮旁的前进、后退箭头可在本次打开窗口后访问过的会话间切换。
- **命令、引用和语音**。输入 `/` 查找命令，输入 `@` 引用文件或会话。输入框下方可选择工作区、权限、模型和推理强度，也可查看用量。DSH 启用语音输入插件时，输入框会显示麦克风。录音和转写使用原生实现，即便切换会话，转写结果仍归入原会话草稿；需配置可用语音服务并授权麦克风。

FPS 通过 DSH 原生会话发送消息。模型可以使用当前配置已启用的工具，由 DSH 按会话权限执行或请求确认。

## 用量怎么显示

点模型选择器旁的圆环。FPS 根据 DSH 中已启用的服务商及其 API Key 查询用量，按适配接口实际返回的内容显示余额、已用金额、额度或重置时间。零余额正常显示。接口未适配、查询失败或缺少数据时，相应账户或字段会自动隐藏。会话 Token 和上下文占用估算由 DSH 提供，单独显示。服务商区块之间有分隔，按名称字母顺序排列，不区分大小写。弹层最多增长到 720 px，同时受屏幕空间限制，超出后才滚动。普通模型 Key 不一定能读取组织级用量，缺失指标不会根据 Token 推算。

## 可选生图工具

在「插件 → Four-pointed star → 图片生成」中按需开启。四项开关默认关闭。服务开启并准备就绪后，支持工具调用的会话模型可以按 DSH 的会话权限使用。FPS 将图片保存到 DSH 的生成目录，可用 DSH 原生预览打开。使用云端生图时，提示词会发送给相应服务，请避免在提示词里写入机密信息。

可以在提示词里指定服务商。FPS 默认提示模型优先使用已有生图工具。调用 FPS 时，会按 ComfyUI（已就绪）、Z-Image Turbo、CogView-3-Flash、Pollinations 的顺序选取可用服务。请求失败时会返回错误，由你决定重试或换用其他服务。

- **Z-Image Turbo**。使用官方 Hugging Face Space，无需 API Key。生成的图片约为一百万像素，适合快速试构图和风格。共享 GPU 繁忙时需要排队，额度用尽时需等服务恢复。ZeroGPU 文档给出的匿名额度为每天两分钟 GPU 时间。[ZeroGPU 额度](https://huggingface.co/docs/hub/spaces-zerogpu#usage-tiers)
- **CogView-3-Flash**。需要智谱开放平台的 API Key。智谱将该 Flash 模型列为免费，适合常规画质需求，实际可用性取决于账号资格、服务限流与运行状态。FPS 只调用这个 Flash 模型。[智谱定价](https://docs.bigmodel.cn/cn/guide/start/pricing)
- **Pollinations**。需要自己的 Pollinations API Key。即使使用零价模型，服务也可能要求账户有正的可用余额。FPS 在请求前检查 SDXL Lightning 的实时价格，仅在零价时调用。该社区模型适合快速打样，模型说明标明会记录提示词和生成结果。[Pollinations API](https://gen.pollinations.ai/docs)
- **ComfyUI + Comfy MCP**。开启开关后，在「图片生成」中启动下载，安装 ComfyUI 和官方 Comfy MCP。安装支持 Apple 芯片的 macOS 14 或更新版本、64 位 Windows，以及 glibc 2.28 或更新版本的 x86-64 Linux。安装需要 Git、带 `venv` 和 `pip` 的 Python 3.11–3.13、网络连接、至少 8 GB 内存和 16 GiB 可用磁盘空间。建议使用兼容的 Apple 或 NVIDIA GPU，CPU 生图可能需要几分钟。随附的 SD 1.5 工作流默认在本地生成约 512 × 512 像素的草图，细小文字和写实效果有限。本地生成无需 Comfy 账号或积分。[Comfy MCP](https://github.com/Comfy-Org/comfy-mcp) · [模型与许可](https://huggingface.co/Comfy-Org/stable-diffusion-v1-5-archive)

仅开启 ComfyUI 不会开始下载，安装提供进度和取消操作。Apple 芯片 Mac 已实测出图，Windows 和 Linux 安装尚未实机验证。免费档和服务可用性可能改变。

关闭 ComfyUI 开关后，本地生图停用，已下载的文件保留供下次使用。FPS 通过官方 MCP 运行入门工作流，会话中只开放生图功能。

在「图片生成」设置中，可将 CogView-3-Flash 和 Pollinations 的 Key 保存至 DSH 的凭证存储。也可以在启动 DSH 的环境中设置 `FPS_COGVIEW_API_KEY` 或 `POLLINATIONS_API_KEY`。各服务使用自己的 Key。

## 自定义

- **外观**。在 DSH「设置 → 通用 → 外观」中选择浅色、深色或跟随系统。FPS 会同步切换侧栏、消息区、输入框和弹层的配色。
- **模型和用量**。在 DSH「设置 → 模型」中添加或编辑自己的服务商、接口地址、模型和 API Key。再次打开用量面板即可按新配置查询。自定义地址的余额或额度需要对应的用量接口适配。使用纯文本模型时，可在同一处添加支持图片输入的模型，供 FPS 自动选择。
- **工具和权限**。在 DSH 的「插件」中管理提供工具的插件，并在输入框下方选择会话模型和权限模式。工具能否调用取决于模型能力和当前会话权限。
